# Расчёт шпунта методом предельных состояний

Программа для расчёта шпунтовых ограждений методом предельных состояний.

🇬🇧 [English version of this README](README_EN.md)

## Как пользоваться

1. Скачайте релиз программы со страницы [Releases](../../releases).
2. Запустите исполняемый файл `shpunt_limit_state.exe`.
3. Выберите расчётную схему из выпадающего списка.
4. В левой части по очереди заполните все вкладки вашими параметрами. Либо нажмите «Загрузить параметры…», если у вас есть готовый файл с заполненными параметрами.
5. Нажмите «Рассчитать» (или Enter в любом поле).

## Пояснения от автора

В ходе работы над программой я обнаружил, что результат расчёта очень сильно зависит от коэффициента m в проверке M_opr ≤ m·M_ud. Пороговое значение — m = 0.75: при m < 0.75 решения нет ни при какой высоте котлована, при m > 0.75 решение есть всегда. Полагаю, что научному сообществу это известно, и именно поэтому, чтобы математическая модель соответствовала реальности, коэффициенты приходится подгонять. Из этих же соображений я ввёл дополнительный параметр h_ratio_min — проверку h/H ≥ 0.45. Значение 0.45 хорошо подходит для песка, для глинистых грунтов имеет смысл использовать 0.5–0.6. Но вы сами понимаете: грунт не однороден, супесь может перемежаться с глиной, поэтому точно подобрать математическую модель невозможно. Поэтому лучше используйте мою программу для расчёта шпунта методом конечных элементов — эта математическая модель более универсальная.
